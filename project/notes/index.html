Notes: Personal Blog

A personal blog where publishing a post means writing one Markdown file, and every page ships the metadata search engines and link previews need. I wrote the generator myself instead of using a theme.

open_in_new Visit site → GitHub
photo_camera Screenshot coming soon

Why I Built It

I wanted a place to write about coding, campus life, and the cafés I work from, and a real site to practice SEO on. Building the generator myself meant knowing exactly what every tag on the page is for.

Project Goal

A fast blog with no database to run, where a new post is a file, and every page is correct for search, sharing, and reading on a phone.

RoleSolo developer
PeriodOct 2026
TypePersonal project
ArchitectureStatic HTML from a Node build script (marked), GitHub Pages

What It Does

  • check_circleMarkdown posts with front matter for tags, cover image, and a draft flag; the build fails if a placeholder is left in a published post
  • check_circlePer-page SEO: canonical, Open Graph and Twitter cards, JSON-LD (BlogPosting, breadcrumbs, Person), sitemap, RSS, and robots
  • check_circleAn author page with Person schema linking my profiles, so search engines can tie them to one identity
  • check_circleFloating pill navigation, sidebar with latest posts and topics, and light and dark themes
  • check_circleComments through Giscus (GitHub Discussions), so there is no backend to run
  • check_circleAnonymous visitor counter on a small realtime database

Key Screens

Tech Stack

Node.js Markdown SEO JSON-LD GitHub Pages Giscus

One Node script with marked as its only dependency writes dist/, and GitHub Actions deploys it to GitHub Pages. Comments use Giscus with strict matching on the page path; the trade-off is that commenters need a GitHub account, which suits a developer audience but not every post.
